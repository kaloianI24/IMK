## Color scheme is pinned

`Lighthouse`/headless Chrome follow the host OS `prefers-color-scheme`, so the
same commit scored differently on different machines — and the dark theme is
where the contrast regression lived. `.lighthouserc.cjs` therefore pins Blink's
`preferredColorScheme` (verified against Chromium:
`blink.mojom.PreferredColorScheme { kDark=0, kLight=1 }`):

- this directory = **dark** (CI default, `preferredColorScheme=0`);
- `light/` = **light** (`LHCI_COLOR_SCHEME=light`, `preferredColorScheme=1`).

## Reproduce

```sh
npm run build
npm run lhci                       # dark  (default)
LHCI_COLOR_SCHEME=light npm run lhci   # light
```

`CHROME_PATH` selects the browser (CI uses the runner's Chrome automatically;
Windows dev machines default to Edge).
