## 5. Home hero screenshot spec (`what to capture for T5`)

- **Content:** a real automation running in your own account — e.g. a Make/n8n scenario canvas or Zapier flow, or an internal tool dashboard. Capture the tool chrome so people can recognise the product (recognisable integrations, a trigger module, a successful run badge).
- **Aspect ratio:** `--aspect-hero` (16/9); capture at **1920×1080** min, export WebP + AVIF with `sizes`.
- **Crop / treatment:** crop to a single coherent panel; no blur, no #FF0000-style colour bars. Light overlay allowed (1–2% black scrim) only to unify light canvas.
- **File names:** `public/work/hero-automation.webp` (+ `.avif` generated by T5 image service); do **not** hot-link to vendor dashboards.
- **Caption:** “One automation in our accounts, not a mockup.” (visible + alt) — if the screenshot is of a sample project, label it `Sample project`.
- **Alt text formula:** “Screenshot of {tool} showing a workflow that {outcome}.” e.g. “Screenshot of Make showing a workflow that routes enquiries from a web form to a CRM.”
- **No stock photography anywhere on site.** Hero, avatar, case study screenshots must be real captures by the owner; if unavailable, ship the reserved placeholder frame + empty-state copy slot, not an illustration.

Do not ship the token unchanged without re-running this calculation after any parent colour change.

### 7b. Dark accent ramp re-measure (accessibility defect fix)

**Defect:** in the dark theme the accent `--color-primary` / `--color-link` `#E04B67` sat on `--color-surface` `#1F1B1E` at **4.35:1** — below the 4.5:1 required for normal-weight text. It is used as normal text by `a`, `.btn-ghost`, `a:hover`, `.nav a:hover`, `.breadcrumbs a:hover` and the inline `color:var(--color-primary)` spans in `ServiceCard`/`CaseCard`.

**Fix:** nudge the dark accent lightness only; hue (≈349°) and saturation (≈70%) are unchanged, and the light theme is untouched. All figures below are computed relative-luminance measurements (WCAG 2.x), not estimates.

Dark accent ramp — ratio against every surface the accent can appear on:

| Token | Hex | Rel. luminance | on `--color-bg` #121012 | on `--color-surface` #1F1B1E | on `--color-surface-2` #2A2428 | on `--color-neutral-soft` #2F292D |
|---|---|---|---|---|---|---|
| `--color-primary` | `#E4677E` | 0.277 | 5.90 ✓ | 5.30 ✓ | 4.73 ✓ | 4.43 † |
| `--color-primary-hover` | `#EA7C90` | 0.339 | 7.02 ✓ | 6.31 ✓ | 5.64 ✓ | 5.27 ✓ |
| `--color-primary-active` | `#E0526C` | 0.230 | 5.05 ✓ | 4.53 ✓ | 4.05 † | 3.79 † |
| `--color-link` | `#EA7C90` | 0.339 | 7.02 ✓ | 6.31 ✓ | 5.64 ✓ | 5.27 ✓ |

`✓` = meets WCAG 2.2 AA for normal text (≥4.5:1). `†` = pair is not painted as accent **text** anywhere: `--color-primary` is used as text only on `--color-surface` (the “Learn more →” / “Read more →” spans in `ServiceCard`/`CaseCard`, 5.30 ✓); its other uses are a button fill (`.btn-primary`, label checked below), a 4px border (`.callout`) and hover colours on `--color-bg`. `--color-primary-active` is not referenced by any component; it is kept as a coherent ramp member.

**Second finding (found while auditing `/book`).** `--color-link` was initially set to the same `#E4677E` as `--color-primary`. That fails the one place a link actually sits on the *lightest* dark surface: `.banner` uses `--color-neutral-soft` `#2F292D` and on `/book` it contains a real link (“Privacy details”), giving **4.43:1** — under 4.5. `--color-link` is therefore `#EA7C90`, i.e. equal to dark `--color-primary-hover`. That restores the invariant the **light** theme already relies on (`--color-link` = `--color-primary-hover` = `#911631` there) and clears every dark surface with margin. The earlier draft’s note that “`--color-neutral-soft` … carries no accent text” was wrong; `.banner` links are exactly that case. (`.tag`/`.placeholder` on `--color-neutral-soft` use `--color-text-muted` `#B7AEA7` = 6.52:1 ✓.)

Label pairing on the accent as a background fill (`--color-on-primary` `#171315`, normal weight):

| Fill | Label `#171315` ratio |
|---|---|
| `#E04B67` (old) | 4.71 ✓ |
| `#E4677E` (new primary) | 5.74 ✓ |
| `#EA7C90` (hover) | 6.83 ✓ |
| `#E0526C` (active) | 4.90 ✓ |

Light theme (unchanged, for the record): `#B01C3B` 6.67:1 on `#FFFCF7`; `#911631` link 8.68:1; label `#FFFCF7` on `#B01C3B` 6.67:1 — all PASS.
